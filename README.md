# 마이 스타로그 — 기존 스폰노트 주소

v2.0.0: my-starlog v1.2.0의 화면과 기능을 기존 주소에 적용합니다.

스타크래프트 스폰·래더·연습·CK 기록, 복기, 통계, 큰 글씨와 업데이트 확인을 제공합니다.

기존 spawnNote.records.v1 기록을 같은 주소·브라우저에서 자동으로 가져옵니다. 현재 키가 없을 때만 newcatsleSpawnNote.records.v1을 사용합니다. 원본은 삭제하지 않고 별도 백업 다운로드를 제공합니다. 상대 종족은 보존하며, 저장되지 않은 내 종족은 미등록으로 표시합니다. 검증 실패 기록은 원본에 남기고 안내합니다. 저장 실패 시 완료로 처리하지 않습니다. 중복 ID와 이전 완료 ID를 기억해 삭제 기록의 재생성을 막습니다.

새 기록 키는 my-starlog-spwn-note-v1입니다. 다른 주소·브라우저의 데이터는 JSON 백업으로 가져오세요.

검사: node --test tests/*.test.mjs worker/tests/*.test.mjs

이전 화면 테스트는 legacy-tests에 참고용으로 보존합니다. 기존 Worker는 변경하지 않으며 새 UI에서 호출하지 않습니다.
