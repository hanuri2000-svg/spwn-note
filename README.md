# 스폰노트 웹 버전

모바일과 PC 브라우저에서 사용하는 독립 스폰일지입니다.

현재 버전: **v1.8.1**

## 제공 기능

- 날짜, 상대, 티어, 종족, 승패, 빌드, 맵, 패인 직접 기록
- 느낀점과 피드백 저장·검색·전체 보기
- 저장된 스폰일지 기준 전체·월간·주간·종족별 통계
- 저장된 스폰일지 기준 맵별·빌드별·최근 상대 선수 20명 전적
- 기록 수정과 삭제
- CSV 내보내기
- JSON 백업·복원과 전체 리셋
- 앱 안에서 최신 버전 확인 및 업데이트 적용
- 승인된 공용 선수 DB 기반 티어·종족 자동 입력
- 독립 화면에서만 보이는 배경 워터마크와 제작자 표기

## 데이터 저장

스폰일지 기록은 현재 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저로 옮길 때는 **백업 저장**으로 JSON 파일을 받은 뒤 **백업 불러오기**를 사용해야 합니다.

## 외부 전적 연동

v1.8.0부터 ELOBOARD 자동 조회, 전적 가져오기, 대시보드 공식전 통계, 상대전적 검색, 중계 서버 연결 기능을 사용하지 않습니다. 기존에 가져왔던 기록은 삭제하지 않고 일반 스폰일지 기록으로 유지됩니다.

## 티어표

v1.8.1부터 독립 스폰노트의 티어표 메뉴와 SOOP LIVE 조회 기능을 사용하지 않습니다.
